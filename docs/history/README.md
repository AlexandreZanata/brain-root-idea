# Project history

This directory stores reviewed batch records for BrainRoot's Build in Public experiment. GitHub Wiki is updated continuously; the final batch record is normalized here before merge so history remains coupled to the source revision.

## Rules

- One file per batch under `batches/`, named `Bxx-short-name.md`.
- Use `docs/specs/wiki-batch-log-template.md` as the common structure.
- Link every issue, batch PR, final CI run, merge commit, tag/release, ADR, performance report, and matching Wiki page.
- State failed attempts and deviations; do not rewrite history into a success-only narrative.
- Never include secrets, personal data, raw environment dumps, private provider output, or unbounded logs.

The first implementation batch is B00. The current documentation foundation predates the batch workflow and will be summarized on B00's Wiki/repository page rather than fabricated as already-completed GitHub issues.
